# Velora CRM Dashboard

A modern CRM dashboard built with HTML, CSS, JavaScript, and Chart.js.  
This project was created to practice front-end layout, responsive design, dashboard UI, and data visualization.

## Live Demo
[View Live Project](https://crm-dashboard-sable-nine.vercel.app)

## Features
- Responsive CRM dashboard layout
- Sidebar navigation
- Profile card
- Sales performance stat cards
- Revenue chart using Chart.js
- Recent deals table
- Top clients section
- Upcoming activities panel
- Hover effects and modern SaaS-style UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js
- Font Awesome

## What I Learned
- CSS Grid and Flexbox layout
- Building reusable card sections
- Styling responsive dashboards
- Connecting Chart.js to a front-end project
- Organizing a project with separate HTML, CSS, and JS files
